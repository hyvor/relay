> We are currently not accepting outside contributions to this repository. We will update this document when we are ready to accept contributions. In the meantime, please feel free to open issues for bugs or feature requests.

# Contributing to Hyvor Relay

Thanks for your interest in contributing to Hyvor Relay! This document covers
what's specific to this repository. For general HYVOR contribution
guidelines (opening issues, pull request process, code of conduct, etc.),
see [CONTRIBUTING.md at the `hyvor/dev` repo](https://github.com/hyvor/dev/blob/main/CONTRIBUTING.md).

## Development setup

See [DEV.md](DEV.md) for instructions on setting up Hyvor Relay locally.

## AI usage

We allow AI-assisted contributions under certain conditions. Read the
[AI Usage Policy](https://github.com/hyvor/dev/blob/main/AI_POLICY.md)
before using AI tools (Claude Code, Cursor, Copilot, etc.) to work on a
contribution, and disclose any AI assistance in your pull request
description as required by the policy.

## Security issues

Please do **not** report security vulnerabilities through public GitHub
issues. See [SECURITY.md](https://github.com/hyvor/dev/blob/main/SECURITY.md) 
in the `hyvor/dev` repo for how to report them responsibly.
